# Astrarium 0.4.0

An offline planetarium for your terminal, built in Rust on Omarchy.

## Explore

- 5,044 stars and 88 constellation figures.
- Seven planets, the Sun and the Moon, with lunar phases and illumination.
- Mouse dragging, scroll-to-zoom, keyboard controls and object search.
- Progressive star labels, full-sky mode and time controls.
- English by default; press **F2** for Spanish.

## Install on Linux

The attached binary is for **x86-64 Linux with glibc 2.35 or newer**, including
Omarchy and current Arch Linux. Rust and Clang are not required at runtime.

```sh
version=0.4.0
archive="astrarium-$version-x86_64-unknown-linux-gnu.tar.gz"
url="https://github.com/laflechaenelaire/astrarium/releases/download/v$version"
curl -fLO "$url/$archive"
curl -fLO "$url/SHA256SUMS"
sha256sum --check SHA256SUMS
tar -xzf "$archive"
install -Dm755 "${archive%.tar.gz}/astrarium" "$HOME/.local/bin/astrarium"
"$HOME/.local/bin/astrarium"
```

Run each step after the previous one succeeds. On first launch, enter your
location as `Name; latitude; longitude`. Press **?** for controls.

The archive includes documentation and third-party licences. SHA-256 checksums
are provided in `SHA256SUMS`.

Other architectures can [build from source](https://github.com/laflechaenelaire/astrarium#build-and-install).
An Arch `PKGBUILD` is included for local package installation with `makepkg -si`.
Astrarium is not yet published in the AUR.
